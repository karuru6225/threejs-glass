# 引き継ぎ資料 — threejs-glass

最終更新: 2026-11-10

## 1. これは何か

網入り型板ガラス（かすみ模様）越しに外の景色を見る three.js のデモ。部屋の中を歩き回って、窓越しに次の2つの景色を見られる。

- **夜の街**：歌舞伎町風の繁華街。看板、ネオン、車、信号がある。
- **昼の植物**：窓のすぐ外の植え込み。

きっかけは X で見かけた three.js のガラス表現の動画。「これを自分で再現してみる」という流れで、Claude と対話しながら1日で作った。

- 公開中のプレビュー（claude.ai のアーティファクト、本人のみ閲覧可）：https://claude.ai/artifact/NZ4RoYoCMWgADwTQpGVAZF
- このリポジトリの `index.html` は、上のプレビューと同じ内容。

## 4. アーキテクチャ

### 4.1 1フレームの描画順

1. **外の景色**（`city` または植物の `scene`）を、色＋深度の RT（`rt`）に描く。このとき `renderer.clippingPlanes = OUTSIDE_ONLY` で、z > 0（部屋側）にはみ出す形状を切り捨てる。
2. 6フレームに1回、**窓プローブ**（`probeCam`）で外を 32×16 の float RT に描く。左右の平均色を出し、窓の `RectAreaLight` 2枚の色にする。
3. **部屋**（`glassScene`）を EffectComposer で描く。ガラス板の `glassMat` は 1 の `rt` を読む。
4. GTAO → OutputPass（トーンマップ＋sRGB）→ ビネットと粒子の `ShaderPass`。

### 4.2 座標の約束

- **窓**：z = 0 の平面上にあり、開口部の中心は (0, `WIN_Y`=0.1)、大きさは `WIN_W` 1.8 × `WIN_H` 1.2。
- **部屋**：z > 0 側。`ROOM = { x: ±2.5, back: 4.8, floor: -1.3, ceil: 1.45 }`。目の高さは y = 0.15。
- **外の景色**：必ず z < 0 側に置く。
- **夜の街**：`buildCity()` はローカル座標で通りを z 方向に作る。地面は `GROUND`=-1.3、両側の建物の壁面は x = ±`EDGE`(2.6)。それを `cityRoot` で90°回転・平行移動して、通りが窓の前を左右に走るようにしている。ローカル z = `SLOT_Z`(-19)、+x 側の壁面が、ちょうど窓の位置に来る（＝自分の部屋がそのビルの1室）。`inSlot()` の範囲には看板を付けない。
- **単位**：だいたい 1 = 1m のつもりだが、厳密ではない。

### 4.3 ガラスのシェーダー（`glassMat`）

- **模様**：ガラス面のワールド座標 × `uScale` を、値ノイズの fbm（5オクターブ）にかける。画面上で約2px未満になるオクターブは `gFw`（fwidth）でフェードさせる（最初のオクターブは常に残す）。
- **傾き**：高さ場の中心差分で出し、`slope` にする。
- **屈折**：`shiftFor(d, zg)` の分だけ、背景を読む位置をずらす。`d` はガラスから物体までの距離（深度から求める）、`zg` は目からガラスまでの距離。ずれは画面高さ単位で、`uProj` で画角を補正する。ずらした先で深度を読み直して、1回だけ補正している。
- **ぼけ**：`radiusFor(d, zg)` の半径で、24タップのゴールデンアングル配置ディスク。各タップでもそのタップ自身の `radiusFor` を計算し、中心からの距離より小さければ重みを下げる（scatter-as-gather）。これで、ガラスに張り付いた物体が背景ににじまない。色は `textureLod` で mip を併用している。
- **にじみ（halation）**：mip 4.5 と 6.5 段の色を `uGlow` 倍で足す。夜の街は 0.18、植物は 0.04。
- **網**：ピッチ 0.042 の格子。`slope` で少しだけ揺らし、`fwidth` でアンチエイリアス。
- **その他**：ガラスの緑がかった色味、乳白のもや、スペキュラ、フレネル。

### 4.4 夜の街

- **建物**：`facadeTexture()` で窓のテクスチャを作る。窓は白い蛍光灯が中心で、点灯率は低め。
- **壁面看板**：`wallSignTexture()` で作る。`box`（行灯の文字看板）、`led`（青い LED パネル）、`store`（1階の店先）の3種類。歌舞伎町のサムネイル（後述）を参考に、建物の下から2/3くらいを埋める。
- **突き出し看板**：`signTexture()` の縦長・横長の看板と、赤提灯。
- **路面**：鏡面反射はやめて、**拡散反射のみ**。看板の色を、通り方向の 1D テクスチャ `strip`（左右2行）に積算しておく（`stripAdd`）。シェーダーでは壁からの距離に応じてぼかしながら照らす。街灯と車のライトの光だまりは解析的に計算する。横断歩道もこのシェーダーで描く。
- **車**：箱の車体の前面にヘッドライト、後面にテールランプを片面ポリゴンで貼っている。なので近づく車はヘッドライト、遠ざかる車はテールランプが見える。
- **交通**：`updateCity()` が担当。各車線をループとして扱い、前の車との車間で目標速度を決める。加速は穏やかに、減速は強めに。前の車に重ならないよう、移動量も制限している。信号（14秒周期）が赤のとき、黄でも止まれる距離のときは、`STOP_LINE` で停止する。
- **確認**：`npm run sim:traffic` で120秒回し、最小の車間が正であることを確認できる。

### 4.5 部屋

- **窓の光**：`RectAreaLight` 2枚（左右のガラス戸）。色は窓プローブの平均色 × `SCENES[*].win`（夜 110、昼 14）。プローブは窓位置から広角で撮るので、カメラの向きに依存しない。
- **天井照明**：影ありの `PointLight` で、`setLamp()` でオン／オフ。初期値はどちらのシーンもオフ。
- **素材**：漆喰（バンプ）、フローリング（canvas で描いた木目＋ラフネスマップ＋クリアコート）、木枠、アルミ（RoomEnvironment の PMREM を低い強度で使う）。
- **小物**：巾木、カーテンレール、コンセント、丸い天井照明。

### 4.6 操作

- **WASD**：カメラの実際の向きから水平の前方と右方向を出して移動する。以前、yaw の符号を取り違えて移動方向がずれるバグがあり、修正済み。
- **移動範囲**：部屋の中に制限してある。窓の開口部の中までは入れるが、ガラスより外には出られない。
- **デバッグ用**：`window.__glass`（`player`、`winCol()`、`setLamp()`）を露出している。

## 6. 決定事項と経緯（なぜこうなっているか）

- **配色**：検索で出る写真は青く加工されたものが多く、それは**参考にしない**、というのが本人の指示。最終的には YouTube の動画「東京新宿歌舞伎町夜の 夜景ネオン街風景」のサムネイル（`i.ytimg.com/vi/Dd1qA1s1aCs/hqdefault.jpg`）に寄せた。特徴は次のとおり。
  - 空は真っ黒。
  - 建物の上の方は暗い。
  - 看板の色は赤、マゼンタ、紫、黄、白で、青い LED が1棟と緑が少し。
- **路面**：最初は鏡像の反射だったが、「強すぎる、弱い拡散反射だけに」という指示で今の方式にした。
- **窓の配置**：最初は通りの突き当たりから見下ろす構図だった。「背景のどこかのビルにある窓」という指示で、今の配置にした。
- **看板の明るさ**：明るくしすぎると、ガラス越しで全体が白飛びして色が分かれない。看板の間に黒い隙間を作るのが、見た目上いちばん効いた。
- **模様の細かさ**：単純に細かくすると砂のようになって型板らしさが消える。そこで LOD フェードを入れ、UI で調整できるようにした。

   1. GTAO を外す
   2. 影の mapSize を下げる
   3. ガラスのタップ数（N=24）を減らす
   4. DPR の上限（1.5）を下げる
3. **ファイルを分割する**：`index.html` が大きいので、`src/` に分けるとよい（glass / city / plants / room / controls / main）。Vite で動く状態なので分けやすい。
4. **窓プローブのフォールバック**：float RT を `readPixels` で読むには `EXT_color_buffer_float` が必要。読めない環境では `probeOk=false` になって窓の光が黒いままになる。HalfFloat で読む（`Uint16Array`）か、固定色にフォールバックする処理を入れたい。

## 8. 既知の問題・制約

- 植物シーンで、ガラスに近い葉の縁が少しガサつく（ぼけのエッジ処理の限界）。
- ぼけに mip を使っているので、手前の物体のすぐ横に、わずかなハロが出ることがある。
- 窓の光は平均色なので、看板の形が室内に投影されるわけではない。すりガラスなので、物理的にもおおむね妥当。
- 看板の文字は canvas の `sans-serif` で描くので、OS のフォントによって見た目が変わる。日本語フォントがないと豆腐になる。
- 車は通りの端でループ（瞬間移動）している。窓から斜めに覗くと、端が見える可能性がある。
- 外部ライブラリを読むのは CDN（jsDelivr）からで、three は 0.170.0 に固定している。

## 9. 確認の仕方（これまでのやり方）

- 見た目は、Playwright とヘッドレス Chrome（`--use-angle=swiftshader`）のスクリーンショットで確認していた。
  - `window.__glass.player` を使うと、視点を任意の位置・向きにできる。
  - 「押してガラスを外す」ボタンに `pointerdown` を送ると、ガラスなしの景色を撮れる。
- 交通ロジックは `npm run sim:traffic` で確認する。
