# threejs-glass

網入り型板ガラス（かすみ模様）越しに景色を見る three.js のデモ。
部屋の窓から、夜の繁華街（歌舞伎町っぽい通り）か、昼の植物を眺める。

**デモ: <https://karuru6225.github.io/threejs-glass/>**

## 動かし方

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ に静的ファイル
```

`index.html` は単体でも動く（importmap で three.js を jsDelivr から読む）。
npm を使わず `npx serve .` などの静的サーバーで開いてもよい。Vite 経由のときは npm の `three` が使われる。

## 操作

| 操作 | 内容 |
| --- | --- |
| WASD / 矢印キー | 移動（Shift で速く） |
| ドラッグ | 見回す |
| 夜の街 / 植物 | シーン切り替え（URL の `#city` / `#plants` でも可） |
| 屈折・模様の細かさ・ぼかし・景色の距離 | ガラスのパラメータ |
| 網 | 網入りの網の表示切り替え |
| 押してガラスを外す | 押している間、ガラスなしの景色 |
| 照明 | 天井照明のオン／オフ |

スマホでは右下に移動用ボタンが出る。

## 仕組み

描画は 1 フレームに次の順で行う。

1. **窓の外**（`city` / `scene`）を、色＋深度つきのレンダーターゲットに描く。ガラス面より手前（部屋側）はクリッピングで捨てる。
2. **部屋**（`glassScene`）を EffectComposer で描く。ガラス板は自前の `ShaderMaterial` で、1 の結果を読む。
3. GTAO（部屋の隅の陰り）→ トーンマップ → ビネット＋粒子。

### ガラスのシェーダー

- **模様**：ガラス面のワールド座標を値ノイズの fbm にかけた高さ場。差分で傾き（法線）を出す。画面上で 2px 未満になるオクターブはフェードさせてチラつきを防ぐ。
- **屈折**：傾きの分だけ背景の読み取り位置をずらす。ずれ量は「ガラスから物体までの距離 d」と「目からの距離」で決まる（`shiftFor`）。
- **ぼけ**：深度から d を出し、`radiusFor(d)` の半径で 24 タップのディスクぼかし。各タップ自身のぼけ半径も見て（scatter-as-gather）、ガラスに近い物体がにじみ出さないようにしている。
- **にじみ**：明るい光がガラス内で広く散る分を、ミップマップの低解像度段から足す（夜の街で強め）。
- **網**：ガラス内部にある前提で、ぼかさず、表面の傾きで少しだけ揺らす。

### 夜の街

- 通りは `buildCity()` で手続き生成。壁面看板（行灯）、突き出し看板、ネオン、赤提灯、街灯、信号、電柱。
- `cityRoot` を回転・移動して、部屋が通り沿いのビルの 1 室になるよう配置（`SLOT_Z` の位置）。自分の窓の外には看板を付けない。
- 路面は拡散反射のみ。看板の色を通り方向の 1D テクスチャに積算しておき、壁からの距離に応じてぼかして照らす。街灯と車のライトの光だまりは解析的に計算。
- 車は箱の車体の前面にヘッドライト、後面にテールランプを片面ポリゴンで貼ってあり、向きで見え方が変わる。同じ車線の前の車との車間で減速し、赤信号では停止線で止まる。

### 部屋

- 窓の位置に置いた広角のプローブカメラで外を 32×16 に描き、左右のガラス戸ごとの平均色を出して `RectAreaLight` の色にする（すりガラスなので光は拡散）。
- 天井照明は影つき PointLight。床・壁・木枠のテクスチャは canvas で手続き生成。
